# 研究提案 v1.1

## 60M @ 0.1C 追平 600M：参数-数据联合前沿上的判定实验与架构搜索

- 状态：draft for review（对应 SPEC v1.1）
- 前置文档：`research/SPEC.md`（定义、协议、预算、账本格式）
- 一句话目标：**在锁定的任务分布上，检验是否存在一个总参数 ≤ 60M、训练计算 ≤ 0.1×C_ref、推理成本 ≤ 参考 600M 的模型，其 bits-per-byte 达到 compute-optimal 600M 的水平；若不存在，输出一个可发表的否定结果与精确的缺口分解。**

---

## 1. 问题是怎么被修正的

原始问题“是否存在 60M 参数、训练更快、能力达到 600M 的未发现架构”有三个结构性错误，本提案 v1.1 按以下修订展开：

1. **绑定约束是数据/计算效率，不是参数效率。** 在固定计算预算下，参数共享、循环、隐式深度只是把资源从参数轴换到串行计算轴；它们买显存，不买计算。
2. **问题是否良定取决于缩放律拟合。** Hoffmann 拟合下 60M 的渐近地板低于目标（2.6113 < 2.7296，可行）；Besiroglu 重拟合下地板高于目标（2.7668 > 2.6716，不可行）。必须先做判定实验，否则一切架构工作在未定义的目标上优化。
3. **“能力”必须被分解。** 知识分量受 2 bit/param 的存储下界约束，10× 知识缺口在闭卷设定下被定理禁止；技能分量不受此约束。只报总 loss 会把两类不同的问题混在一起。

由此，问题从“找奇迹架构”重写为：

> **Q★：在 (μ_N, μ_D) 平面上，各效率杠杆的增量向量与交互矩阵是什么？它们的可达集是否与 60M@0.1C 的等值线相交？**

## 2. 目标与三个赛道

资源向量（完整定义见 SPEC §3）：

\[
\mathcal R=(N_{\text{mem}}, C_{\text{train}}, c_{\text{inf}}, M_{\text{kv}}, d_{\text{ser}})
\]

主赛道锁前三项：\(N_{\text{mem}}\le 60\text{M}\)（total，含 embedding）、\(C_{\text{train}}\le 0.1\,C_{\text{ref}}\)、\(c_{\text{inf}}\le c_{\text{ref}}\)，上下文 4096，主度量 bits-per-byte（BPB）。

| 赛道 | 口径 | 教师/过滤器 FLOPs | 预期结论 |
|---|---|---|---|
| A（对照） | 闭卷，总账 | 全部计入 | 知识分量被 B1 定理禁止；可能总 BPB 达标、P1 分域必然不达标 |
| **B（主线）** | 闭卷，摊销 | 教师/过滤器作为一次性基础设施摊销 | 技能分量可达；知识分量系统落后 |
| C（退路） | 开卷，允许非参数检索 | 计入；存储字节进 \(\mathcal R\) | B1 被合法绕过；“60M 模型”需重新定义 |

**参考目标（两个，缺一不可）：**

- \(T_{\text{opt}}=2.7296\) nats/token：Hoffmann 常数下 600M@12B；
- \(T_{\text{pes}}=2.6716\) nats/token：Besiroglu 常数下 600M@12B。

成功分两级：S1 = 达到 \(T_{\text{opt}}\)（只在 Hoffmann 拟合下成立）；S2 = 达到 \(T_{\text{pes}}\)（对两个拟合都稳健）。两级的差距本身就是论文的一部分。

## 3. 数学骨架（全部数值可复算）

### 3.1 参数缺口的闭式分解

设 \(N_s=N_t/10\)，\(C_s=\gamma C_t\)，则 \(D_s=10\gamma D_t\)，

\[
\Delta L=A N_t^{-\alpha}(10^{\alpha}-1)+B D_t^{-\beta}\big((10\gamma)^{-\beta}-1\big)
\]

第一项 **= 0.5002 nats，与数据预算无关**；第二项在 \(\gamma=0.1\) 时为 0。所以 60M@0.1C 与 600M@12B 的差距就是 0.5002 nats（对过训练 20× 的 600M 参考点，只要预算按同样比例缩放，缺口逐位不变）。

### 3.2 等值线：目标不是 10× 参数效率

目标 excess \(T=A N_t^{-\alpha}+B D_t^{-\beta}=1.0396\)。定义

\[
\mu_D(\mu_N)=\left(\frac{B}{(T-A(\mu_N N_s)^{-\alpha})\,D_t^{\beta}}\right)^{1/\beta}
\]

| \(\mu_N\) | 1.00 | 1.60 | 2.00 | 2.70 | 3.00 | 5.00 | **7.26** | 10.0 |
|---|---|---|---|---|---|---|---|---|
| \(\mu_D^{\min}\) | 367.2 | 23.9 | 11.6 | **5.57** | 4.52 | 2.04 | **1.34** | 1.00 |
| \(\mu_C=\mu_N\mu_D\) | 367 | 38.2 | 23.1 | **15.0** | 13.6 | 10.2 | **9.71** | 10.0 |

- 纯数据角点 \(\mu_D=367.2\)（对应 breakeven \(\gamma^*=36.7\)，60M 需 4.41T tokens）；
- 最小有效计算乘子 \(\mu_C^{\min}=9.71\)，在 **(7.26, 1.34)**；
- 此前“2.7/5.57 混合点在射程内”仍对，但它是次优点（\(\mu_C=15.0\)，比最小点多付 55%）。

**含义：可行性取决于 \((\mu_N,\mu_D)\) 的方向，不取决于标量乘积。** 例如 \(\mu_N=1.60,\mu_D=6.47\) 的乘积是 10.3，但 excess=1.153，仍差目标 0.113 nats。

### 3.3 循环引理（v1.1 精确版）

\[
\mathcal F_{\text{looped}(k,N)}\subseteq \mathcal F_{\text{untied}(k\cdot N)}
\]

故在近似误差主导、优化充分时，循环的最优损失不低于 \(k\) 倍参数的非循环网络。固定 \(C=0.1C_t\)、\(N=60M\) 时，最优训练展开

\[
k^*=\left(\frac{\alpha A(60M)^{-\alpha}}{\beta B D_t^{-\beta}}\right)^{1/(\alpha+\beta)}=2.60
\]

收益仅 **0.0658 nats = 所需量的 13.2%**。\(k=12\) 时仅 \(E+B\) 项 = 2.9303 > 2.7296，训练侧 \(k>3\) 被数据项杀死。

**但训练展开与推理展开必须分开**：\(c_{\text{inf}}\le c_{\text{ref}}\) 允许 60M 块在推理时展开 \(k_{\text{inf}}\in[4,8]\)（按 profiler 实测定上界，见 SPEC §6）。B3（深度解锁）在推理侧才可能兑现；代价是新增可证伪假设 **H4：迭代次数泛化**（train k < deploy k 仍有效）。

### 3.4 四条可测的界

- **B1 知识容量（硬界）**：约 2 bit/param。60M → 15 MB 事实；600M → 150 MB 事实。闭卷、总账口径下，知识分量 10× 追平被禁止；总 loss 追平不被禁止（技能分量可补偿）。
- **B2 时间界 Kolmogorov 复杂度**：用 \(Kt(x)=\min_p |p|+\log t(p)\) 替换裸 UTM 论证。循环/共享本质是在 \(|p|\) 与 \(\log t\) 之间交换；固定计算即固定 \(t\)，无免费空间。
- **B3 深度/串行界**：常数深度、对数精度 Transformer ⊆ 均匀 \(\mathsf{TC}^0\)（Merrill & Sabharwal）。迭代群乘法/S5 状态追踪的分离是**条件性**的（依赖 \(\mathsf{TC}^0\ne\mathsf{NC}^1\)，目前开放）；引用必须带条件，或改用无条件深度分离任务（迭代函数复合类）。B3 的正确身份是“诊断语言中深度敏感成分”，不是对 600M 前沿的必胜论证。
- **B4 状态检索下界**：长度 \(L\) 上下文的精确复制/联想召回，任何 \(s\)-bit 状态的循环模型需要 \(s=\Omega(L\log V)\)。因此 SSM 通道必须与精确注意力通路混合，窗口注意力不是可选项。

### 3.5 杠杆乘子与真正的科学问题

候选杠杆的经验乘子（<100M 尺度、待 E1 实测）：

| 杠杆 | 乘子 | 记账 |
|---|---|---|
| 优化器（Muon/SOAP/Shampoo） | 1.3–1.6× | 无 |
| 数据筛选/课程 | 2–4× | 筛选模型 FLOPs |
| 教师蒸馏 | 3–10× | 教师预训练 FLOPs（仅摊销口径） |
| 合成数据 | 2–5× | 生成器 FLOPs |
| MTP/辅助目标 | 1.1–1.25× | 无 |
| Tokenizer/patching | 1.1–1.4× | 无 |
| 现代稠密架构 | 1.05–1.2× | 无 |
| 循环 \(k\le3\)（训练侧） | ≤1.33× | 无 |
| MoE | 2–4× | 违反 \(N_{\text{mem}}\) |

朴素乘积 ≈10.3 但代入等值线不达标（差 0.113 nats）——**这正是 Q★ 的存在理由**：

> **Q★（v1.1）：估计每个杠杆的雅可比 \((\Delta\log\mu_N,\ \Delta\log\mu_D)\) 与两两交互；判断可达集的并集是否与等值线相交。一个标量 \(\rho\) 不够，要 2×2 的乘子协方差。**

这是文献中几乎没有被系统做过的测量，而且无论最终 yes/no 都有独立价值。

## 4. 架构假说 v1.1

保留“循环异构块 + 状态通道 + 窄注意力”的直觉，但按上述界重新约束：

| 组件 | 参数 | 说明 |
|---|---|---|
| 词表嵌入（tied，6.4k × 768） | ≈4.9M | 沿用 Viby 现有 tokenizer |
| 循环块 \(T_\theta\)（8L × 768，MLA + SwiGLU + RMSNorm + QK-norm，含块内 norm） | ≈52M | 每块一次前向 ≈ 现有 round11 配置 |
| per-step 调制 + MTP 头（若开）+ 其他 | ≈3M | FiLM 式 scale/shift，打破层同质性（ALBERT 已知失效模式） |


**关键约束：**

1. \(k_{\text{train}}\)：训练时对展开次数采样，均值 ≤ 2.6，偶发 \(k=10\)（H4 的训练条件）；\(k_{\text{inf}}\) 上界由 \(c_{\text{inf}}\le c_{\text{ref}}\) 的 profiler 实测决定，预期 4–8。
2. 循环的定位是**解锁深度敏感能力（B3）与 13% 的 N 轴收益**，不是省计算。
3. 注意力通道保留（MLA 全注意力，ctx 4096）：B4 的必然推论。
4. 超网络路线先做廉价预验证：对公开 600M checkpoint 做逐层 PCA / 低秩+稀疏分解，若 99% 损失保持所需内在维度 > 60M 参数的 2/3，直接毙掉该路线。
5. DEQ 只作为显存优化（\(O(1)\) 内存），**不宣称省训练计算**：反向解 \((I-J)^{-1}v\) 仍需 Krylov 迭代。

## 5. 实验计划与计算预算

总预算封顶 **≤ 6×10^19 FLOPs ≈ 42 H100-小时（40% MFU）≈ 8×H100 一晚**；每阶段有 kill gate。完整协议见 SPEC §7。

| 阶段 | 内容 | 预算 | 判据 |
|---|---|---|---|
| P0 | 本仓库 MLX pilot：30M 单点复现 + 账本/BPB 管线打通 | ≤3×10^17 | 口径自洽 |
| **E0** | O2-lite（60M 渐近地板锚点）+ M0 重拟合 \((E,A,\alpha,B,\beta)\) | ~3.2×10^19 | 若 60M 地板 CI 全部高于 \(T_{\text{pes}}\) → 发表否定结果并终止 A/B |
| E1 | 16 组 \(2^{6-2}_{\text{IV}}\) 部分因子设计 @30M/0.6B，估计杠杆雅可比与交互 | ~1.7×10^18 | 若可达集与等值线不相交 → 转摊销口径或终止 |
| E2 | P1–P4 合成诊断（≤10M 模型） | ~1×10^17 | 单机制 <3× 即淘汰 |
| E3 | 前 2 组合 @60M/12B + O3 蒸馏 + O4 无教师 | ~1.6×10^19 | 双目标 S1/S2 判定 |
| Buffer | HP 搜索、架构搜索、复现 | ~1×10^18 | 全部记账 |

**顺序：E0 的 O2-lite 先跑；P0 与 E0 可并行。** 真“D→∞ 饱和”不可负担（60M@192B 就要 6.9×10^19），O2 用双锚点 + Hoffmann/Besiroglu 双先验外推实现。

## 6. 交付物（无论成败）

1. **可发表的否定/肯定结果**：60M@0.1C 对 600M 前沿的 BPB 缺口、知识/技能分解、分域分解。
2. **乘子协方差矩阵**：6–8 个效率杠杆的主效应 + 二阶交互（E1）。这是社区缺少的公共品。
3. **逐架构的五参数缩放律**：\(E,A,\alpha,B,\beta\) + bootstrap CI + 加性形式检验（M0/M4）。
4. **计算账本工具**：双口径（摊销/总账）FLOP ledger 格式与校验脚本。
5. **探针套件**：B1–B4 各对应一个 probe（P1–P4），可复用于后续架构评估。

| 风险 | 概率 | 对策 |

| E0 显示 Besiroglu 拟合在小 N 端成立（问题不成立） | 中 | 按计划发表否定结果；转赛道 C |
