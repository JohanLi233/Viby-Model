# 谱整形的数学：等变性分类、RMT 最优形式与可证伪预测

写于 2026-08。回答的问题：**数学上是否存在一个成立的、未被发现的、比现役
谱整形更好的更新形式？**

答案分三层，每层都可检验：

1. **分类**：等变、无状态的更新规则 ≡ 联合谱映射——要找的空间就这么大，
   且现役所有方法（classic/PE/cubic5/Pion/HTMuon/frac）都在里面（§1）。
2. **该空间内存在闭式最优解**：在「动量 = 持久信号 + 新鲜噪声」的 spiked
   随机矩阵模型下，最优谱映射是 **shrink-then-whiten（Wiener-polar）**
   t*(σ)，闭式可写、已数值对拍（§2–§3，`experiments/probe_rmt_shrinker.py`）。
   Muon 文献（截至 2026-08 检索）没有人写下这个形式。
3. **统一解释力**：本仓库全部六个正负实测结果（PE/classic/cubic5/无 NS/
   stale-D/per-head）都被 t* 框架一致解释，且给出五条可证伪的定量预测（§4–§5）。

---

## 1. 更新规则的分类定理：在哪个空间里找

设更新规则 Φ: ℝ^{m×n} → ℝ^{m×n} 作用于动量 M。若 Φ 满足两条：

- **等变性**：Φ(QMR) = Q·Φ(M)·R 对一切正交 Q∈O(m), R∈O(n)；
- **无状态**：Φ 只看当前 M，不携带跨步记忆；

则由 von Neumann 型表示定理（各向同性矩阵函数的经典结果），Φ 必形如

```
Φ(M) = U · diag(τ) · Vᵀ，  M = U diag(σ) Vᵀ，  τ = f(σ₁,…,σₙ)
```

即**奇异向量不动、谱被（联合）标量映射重塑**。注意 τ_i 允许依赖全部
σ（联合谱函数）——归一化、按分位数自适应都合法；现役文献把自己限制在
**可分离多项式** τ_i = p(σ_i) 这个真子集里，这是第一个"未开发"维度。

跳出该空间只有三条数学通道（对应 `OPTIMIZER_RESEARCH.md` 的 Track C/D）：

| 通道 | 数学含义 | 实例 |
|------|----------|------|
| 破坏等变性 | 损失只对行/头的**置换**不变，不对旋转不变；行有神经元语义 | NorMuon 行归一、RowFloor、Aurora、per-head |
| 引入状态 | 用整个滤波历史估计信号（更大有效样本量） | 二阶矩、Dion 误差反馈、SOAP 基 |
| 引入曲率 | 度量从谱范数换成 loss 的局部各向异性度量 | Mousse / 白化信赖域 |

本文聚焦第一层空间内的最优解；三条通道的机会已在研究计划中排期。

## 2. 统计模型：动量 = 持久信号 + 新鲜噪声

**模型**：F-归一后的动量 X = S + E，信号 S = Σ_k s_k u_k v_kᵀ 低秩且跨步
持久；噪声 E 为 iid 项（entry 方差 σ_e² = w/(mn)，w 为噪声占 Frobenius
能量的比例）。EMA(β) 使噪声方差按有效样本数 ESS = (1+β)/(1−β)（β=0.95
时 39）衰减，信号相干叠加——这正是动量的统计意义。

**随机矩阵事实**（Marchenko–Pastur / BBP / Benaych-Georges–Nadakuditi）：

- 噪声奇异值形成 bulk，上边缘 **λ₊ = √w·(1/√m + 1/√n)**（F-归一口径）。
- 强度 s 的信号 spike 只有超过检测阈时才把观测奇异值推出 bulk；
  观测方向 u_obs 与真方向 u 的重合度有闭式（记 c=m/n≥1，θ=s/(σ_e√n)）：

```
cos²θ_u = (θ⁴−c)/(θ⁴+cθ²)，   cos²θ_v = (θ⁴−c)/(θ⁴+θ²)     [θ > c^{1/4}]
```

  在 bulk 边缘处重合度**连续地降为 0**（BBP 相变）——低于边缘的方向
  与信号渐近正交，是纯噪声。

**数值对拍**（probe_rmt_shrinker Part A/C，m=640, n=384）：σ_obs 公式
4 位有效数字吻合；重合度在 θ/θc≥1.2 误差 <0.02（相变点附近有 O(n^{-1/3})
有限尺寸效应）。EMA 玩具模型中：动量噪声水平与 ESS 预测比值 0.997，
方向-信号重合度在预测边缘处坍缩（σ/edge=1.27 处实测 0.757 vs 理论
0.760；σ/edge=0.98 处掉到 0.10）。模型成立。

## 3. 空间内的最优解：shrink-then-whiten

**推导**。Muon 哲学的理想更新是**信号的极因子** Σ_k u_k v_kᵀ（白化信号，
等权所有真实下降方向）。但我们只能沿观测二元组 {u_i v_iᵀ} 行动：
Δ = Σ_i τ_i u_i v_iᵀ。两种自然目标给出同一形状：

- 最小二乘投影：min_τ E‖Δ − Σ_k u_k v_kᵀ‖_F² ⟹ τ_i = ⟨u_i v_iᵀ, u_k v_kᵀ⟩
  = cosθ_u·cosθ_v；
- 匹配滤波：max E[⟨S_polar, Δ⟩] s.t. ‖Δ‖_F 定 ⟹ τ ∝ cosθ_u·cosθ_v。

（整体尺度被 lr/hyperball 吸收，形状是唯一自由度。）于是：

```
t*(σ) = cosθ_u(θ̂)·cosθ_v(θ̂) = (θ̂⁴ − c) / (θ̂³ · σ/(σ_e√n))    [σ > λ₊]
t*(σ) = 0                                                        [σ ≤ λ₊]

θ̂²(σ) = ½[ y − 1 − c + √((y−1−c)² − 4c) ]，  y = (σ/(σ_e√n))²
```

三个性质：

- **形状**：σ 略高于 λ₊ 时部分权重（该方向大半是噪声，只给重合度那份），
  σ ≫ λ₊ 时 → 1（完全白化）；σ ≤ λ₊ 时 0。这正是"膝盖 + 平坦带"，
  但膝盖位置与过渡形状不再是超参——由 (m, n, w) 决定。
- **合法性**：t* 单调有界 ⟹ 它是某个凸谱罚 φ 的正则化线性极大化解
  （argmax⟨M,X⟩−φ(X) 形式，例：硬膝盖+平带恰是「谱范数球 ∩ 核范数罚」
  的解）⟹ 镜像下降几何存在，标准收敛理论适用。它不是启发式。
- **与 Gavish–Donoho 最优奇异值收缩的关系**：GD 的目标是重建信号矩阵
  本身（τ_GD = ŝ·cosθu·cosθv）；这里目标是白化的信号（去掉 ŝ 因子）。
  一字之差，但正是 Muon 语境需要的对象——**"白化目标下的最优收缩"
  在 RMT 文献与 Muon 文献之间是个空白**，这就是问题问的"数学成立、
  未被发现的形式"。

**关于"迭代不可能定理"**：Muon-p（arXiv 2606.13867）只排除固定单变量
多项式迭代收敛到分数幂 σ^p。t* 在大 σ 处趋于常数 1——正是 NS 型迭代的
自然吸引子，所以 t* 与迭代实现**兼容**（cubic5 本身就是一个膝盖放错
位置的粗糙 t*），不受该定理限制。

## 4. 与本仓库全部实测的一致性

统一机制：**给零重合度（噪声）方向的权重 = 纯方差注入，一阶有害；
信号方向内部的带宽波动被 lr 吸收，二阶无害。**

| 实测 | t* 框架解释 |
|------|-------------|
| PE5 +0.14（t(1e-3)=0.86） | σ=1e-3 在任何合理 w 下都远低于 λ₊（≥0.014），纯噪声方向被给到 0.86 满权——最大方差注入 |
| classic 基准（t(1e-3)=0.47） | 同一方向半权，伤害减半 |
| cubic5 −0.08（t(1e-3)=0.12） | 接近 t* 的 0，最少方差注入——三点单调性与理论方向一致 |
| 无 NS 只归一化 +0.34 | τ ∝ σ：头部 spike 独占步长，中等强度**真信号**方向权重不足——欠白化，另一侧失败模式 |
| stale 极因子 −0.4~0.5 | 对**已旋转走**的方向给满权 = 极端形式的零重合度满权；warmup 期动量旋转最快 ⟹ 伤害最大 ✓ |
| per-head NS −0.14 | 切成 64×768 后 λ₊ 升为整矩阵的 ~1.8×（Part B1：0.161 vs 0.065@w=1），同一套系数下被抬满的噪声质量翻倍。也解释 Pion 论文"per-head 只有配合高通才有益" |

六个独立观测、一个机制、零自由参数拟合——这是该理论最强的证据。

## 5. 可证伪的定量预测

1. **膝盖定位**：最优膝盖 ≈ λ₊ = √w·(1/√m+1/√n)，各形状不同
   （Part B1 表：qkv 0.065·√w，专家栈 0.087·√w，per-head 0.161·√w）。
   现役所有 preset 的 knee50（classic 0.001 / cubic5 0.004 / cubic5b05
   0.010）都**低于** w≥0.025 的任何 λ₊ ⟹ 预测 A1（cubic5b05）不差于
   cubic5，且膝盖继续上移仍有收益，直到越过真实 λ₊ 才 U 转。A2 的扫描
   范围据此定为 knee ∈ [0.01, 0.15] 对数网格。
2. **坍缩点**：A3 快照库中，跨 microbatch 奇异方向相关应在 λ̂₊ 处
   （由 bulk 拟合估计）坍缩，而非渐变（Part C 已在玩具模型确认）。
3. **形状标度**：各层最优膝盖之比 = (1/√m+1/√n) 之比（可用 per-shape
   系数表直接检验；per-head 若重开必须配 1.8× 膝盖）。
4. **批大小 / EMA / 进程依赖**：w ∝ 每步梯度噪声/ESS；warmup 早期
   ESS<39 ⟹ 膝盖应更高（与"warmup 最不能省"的 r082 观察一致），
   膝盖 schedule 的方向由此定：**从高到低**。
5. **剩余空间**：cubic5 在 σ∈[3e-3, λ₊] 仍给 0.35~1.0 的权重
   （Part B3 行），t* 给 0 ⟹ 质量还有未收割的余量（幅度待 A2 标定）。

任一条被否证都约束模型（各向异性噪声 / 非 spiked 信号谱，见 §7）。

### 5.1 预测裁决（2026-08-25，P-1~P-4 实测后）

| # | 预测 | 结果 |
|---|------|------|
| 1 | 最优膝盖≈λ₊ 闭式、膝盖上移有收益直到越过 λ₊ | **半对**：膝盖上移有收益到 b05 后 U 转（b10 +0.07~0.09）✓；但 λ₊ 闭式定标失败（P-1：谱非 MP+spikes，各向异性 10²~10⁴），最优膝盖由实测持续边界 σ* 取代 ✗→修正 |
| 2 | 跨 microbatch 方向相关在 λ̂₊ 处坍缩 | **形式对、位置修正**：ρ(σ) 确实坍缩（且比预测更锐利，近阶跃），但坍缩点 σ*≠λ̂₊（MP 拟合不可用）；σ* 直接无假设测量即得 |
| 3 | 形状标度 = (1/√m+1/√n) 之比 | **未证实**：per-head 膝盖补偿 ×1.9 无害化（P21）但 P21b 显示不补偿也无害——r082 的 per-head 危害不可复现，系旧栈交互；逐形状 σ* 实测（P-1 表）与 MP 比率不符 |
| 4 | 膝盖应随批大小 √B 缩放 | **未证实**：bs6 下 b07(=0.05·√2) 不优于 b05（+0.02 噪声内，P22） |
| 5 | cubic5 在 [3e-3, λ₊] 的剩余权重余量可收割 | **方向对**：左臂（b002）与右臂（b10）双边有害、峰在内点（U 型成立，P20/P17） |

新增预测-裁决对（P-4）：**最优膝盖=实测 σ* 应跨架构复现**——稠密
132M 实测 σ*≈3e-4~1e-3（比 MoE 低一个量级），干预排序单调向低膝盖
改善（b002 3.943 < b10 3.974 < b05 3.997），b002 膝盖恰落在稠密 σ*
上沿。复现成立（以「位置随架构移动」的形式，正是框架的核心主张）。

新增裁决（P28/P29，2000 微步确认档 + P30 晚期快照判别）：**「膝盖=
σ*（下沿）、σ* 以上压平到 1」的二元近似被证伪**。EdgeCubic（逐组
l0=实测 σ*×4.5）在 500 步档中性，2000 步档 mtp 损失单调恶化至
+0.47（P29b edge-only 单变量复现，per-head 排除）。P30（b05 晚期
快照，优化器步 500/750/950）显示 **σ* 全程平稳**（与 warmup 150/300
一致，微步 300→1900 无漂移）——失效的不是测量时点，而是规则本身：
σ* 只是持续信号的**下沿**，其上过渡带（重尾谱下宽达一个数量级）
信号占比仅 0.3~0.7，压平到 1 = 对该带噪声质量过注入。**修正规则：
膝盖（半权点）置于过渡带上沿（信号占比≈1，≈3–10×σ*），或按信号
占比平滑收缩（t* 原形）**。U 型两臂由此统一：左臂=过渡带过注入，
右臂=全持续带欠白化，峰=上沿。

## 6. 实现与成本：数学允许的最便宜点

**实现难度的分水岭在膝盖锐度**（Bernstein 椭圆论证）：

- 单发多项式逼近膝盖在 ℓ 的映射，度 ~ 1/√reg（reg 为膝盖平滑半径）。
  Part D 实测：λ₊=0.029 的平滑 t* 用 deg-8（10 GEMM）仍有 0.33 误差、
  0.32 噪声泄漏——**陡膝盖单发不划算**。
- 迭代复合的有效度指数增长（k 步 cubic = 3^k 次），成本 ~ log(1/ℓ)。
  cubic 家族本来就是膝盖形映射的复合实现。

⟹ **最优实现路径是零新代码的**：保留 cubic 迭代机制，把闭式推导的
l0 从 7e-3 改钉在**每形状组实测的 λ̂₊**上（`cubic5_coeffs(steps, l0=λ̂₊)`
现成），步数随 log(1/l0) 下降自动省 GEMM——理论与降本同向：
l0=λ₊≈0.03~0.09 时 3~4 步足够（6~8 GEMM，vs 现在 10）。

**λ̂₊ 的在线估计**（合法 staleness：标量统计，见 OPTIMIZER_RESEARCH §1.2）：

- 首选：每 K=50~100 步对各形状组代表矩阵做短边 Gram 的 CPU 异步
  eigh（384² 在 CPU 上毫秒级，MLX 统一内存下与 GPU 训练并行），
  bulk 分位数拟合 σ̂_e → λ̂₊；
- 备选：Hutchinson 迹矩（tr G、tr G²）+ MP 矩方程解 σ̂_e，纯 GEMV；
- 最简（先行版）：A3 离线测一次，写死 per-shape 常数表 + 2~3 档
  schedule（warmup 高膝盖 → 稳态低膝盖）。

## 7. 模型边界（诚实节）

- **噪声各向异性**：真实梯度噪声行/列方差不均 ⟹ bulk 变形、边缘偏移。
  修正方向：先行/列白化再谱收缩——**这把 NorMuon 行归一统一成同一理论
  的第一步**（各向异性噪声下的最优估计先做噪声白化）。A3 快照可直接
  检验行方差谱。
  【P-1 实测确认此分支成立：中心化残差行/列各向异性比 10²~10⁴，
  是 MP 定标失败的直接机制，见 OPTIMIZER_RESEARCH §0.5 P-1 结果。】
- **信号非 spiked**：若动量信号谱是连续重尾（HT-SR/HTMuon 的世界观）
  而非低秩 spike，t* 的过渡区形状变化（但"边缘以下置零"仍对）。
  A3 的 bulk-vs-spike 拟合优度直接裁决两个模型。
  【P-1 实测确认此分支也成立：真实动量谱为平滑重尾（Zipf −0.7~−2.7），
  无平台 bulk、无低秩 spike 结构。】
- **理论形态的修正（P-1 后）**：λ₊ 闭式定标在真实动量上失败，但核心理论
  主张存活——「膝盖=信号持续边界」可由跨 microbatch 方向相关 ρ(σ)
  **无假设直接测量**（实测 σ* 逐组稳定、两时点一致），且与全部 7 个
  干预点的最优膝盖零参数对齐。本文的定量主张因此从「λ₊ 公式预测」
  修正为「σ* 直接测量 + 两条干预规则：(a) σ* 以下≈0 权，(b) σ* 以上
  压平到≈1」。
- **非平稳**：信号方向漂移使有效重合度进一步降低（stale-D 机制的连续
  版本），最优 τ 整体下移——方向保守，不影响膝盖位置结论。
  【P30 实测：**σ* 本身在微步 300→1900 全程平稳**（b05 run 优化器步
  500/750/950 与 warmup 150/300 逐组一致），此前 P28/P29 后猜测的
  「σ* 时变」被否——EdgeCubic 失效的真正机制是过渡带过注入，见
  §5.1 末条。非平稳性在这个窗口内不构成边界。】
- 目标函数用 E[下降]−方差 代理了真实训练动力学；最终裁决永远是
  A1/A2 训练 probe。

## 8. 结论

问题的答案是**肯定的，且构造性**：

- 等变无状态类内，比现役全部方法更优的形式**存在且有闭式**——
  t*(σ)（shrink-then-whiten），其膝盖位置 λ₊ 可测、可在线估计；
- 它不是新超参家族，而是把 cubic 迭代的 l0 从"bf16 精度常数"重新解释为
  "噪声 bulk 边缘"——实现是系数表替换，成本随之下降（10→6~8 GEMM）；
- 六个已有实测零参数一致 + 五条新预测可在 M0/M1 里程碑内证伪。

验证脚本：`experiments/probe_rmt_shrinker.py`（BGN 公式对拍 / 生产形状
λ₊ 表 / EMA 坍缩 / 单发拟合成本）。执行路径并入
`research/OPTIMIZER_RESEARCH.md` Track A（理论先行版）。
